# Max Focus: Link Preview

Almost every day we are receiving links for visiting new site or some content in the same page, etc. or read articles and we don't want to lost the focus. For that and more, I bring them this tool.

It is fantastic, it is a freemium, but you can use only the free version and to enjoy you. Same features that it has tool are: preview links, focus only content not distractions, make a questions about the topic of the article, etc.

The tool is: **_[maxFocus](https://maxfoc.us/)_**, you can add to browser and use for more productivity avoiding distractions.

To use it you just have to hold down the left mouse button. More details in this video:
