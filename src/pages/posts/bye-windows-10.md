# Goodbye Windows 10 

Microsoft has announced the end of support for windows 10. It invited all users to use windows 11. It is not only for windows 10, also for windows 7 and windows 8.1. This does not mean that you can not use windows 10 you can still use windows 10 but it will be more vulnerable, for this reason microsoft recommends to change or upgrade to windows 11.

## What is the deadline?

The deadline given by microsoft is until October 2025. The surprise is because after more than 8 years, windows 10 will end the update that is done every year to improve security vulnerabilities. The good news for everyone is that windows 11 is **free**, but for companies the migration is paid.

| Listing | StartDate | End Date |
| ------- | --------- | --------------- |
| Windows 10 Home and Pro | Jul 29, 2015 | Oct 14, 2025 |
