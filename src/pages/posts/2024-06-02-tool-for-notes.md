# Stop using default notes Make better use of this tool

I have found a **free** tool for taking notes.

Get rid of the default notes you use on your devices and start writing in an organized and clear way. This can help you when you need to review old notes. The interface is easy to understand and intuitive. The file organization is folder-like.

You can also synchronize your files at any time. If you need to password protect your files, you can do so.

Finally, when you download the app the data remains in the persistent memory of your device, this app is PWA (Progressive Web App), which means that it can run in your browser and at the same time on your device.

It is very nice and minimalist this app: The link to download it is this: https://opennotas.io/
