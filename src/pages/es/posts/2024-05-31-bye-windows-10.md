<h1 id="goodbye-windows-10">Adiós, Windows 10</h1>

Microsoft ha anunciado el fin del soporte de Windows 10 e invita a todos los usuarios a utilizar Windows 11. La recomendación no se limita a Windows 10: también se dirige a quienes usan Windows 7 y Windows 8.1. Esto no significa que no puedas seguir utilizando Windows 10; puedes hacerlo, pero será más vulnerable. Por este motivo, Microsoft recomienda cambiar o actualizar a Windows 11.

<h2 id="when-is-the-deadline">¿Cuál es la fecha límite?</h2>

La fecha límite establecida por Microsoft es octubre de 2025. La sorpresa es que, después de más de ocho años, Windows 10 dejará de recibir las actualizaciones anuales destinadas a mejorar las vulnerabilidades de seguridad. La buena noticia para todos es que Windows 11 es **gratuito**, aunque para las empresas la migración es de pago.

| Producto | Fecha de inicio | Fecha de finalización |
| ------- | --------- | --------------- |
| Windows 10 Home and Pro | 29 de julio de 2015 | 14 de octubre de 2025 |

Puedes leer más sobre Windows 11 y el fin del soporte de Windows 10 aquí: ***[enlace al aviso de Windows](https://www.microsoft.com/en-us/windows/end-of-support?r=1)***
